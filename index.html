Full Android APK & Lock-Screen Engine

Background Wake, Lock-Screen & Display Over Apps

1. Activate Background & Lock-Screen Engine Ready

Keeps a sub-audible hardware audio lock + Screen WakeLock + high-priority Android Heads-Up Notification active so alarms sound even when your screen is locked or you are in another app.

2. Install Standalone App / Build Signed APK

Download the self-contained app package below. Open it in Chrome on Android and tap "Install App", or upload it to WebIntoApp.com / PWABuilder.com for an instant `.apk`.

3. Native Android "Display Over Other Apps" Bridge

Includes `SYSTEM_ALERT_WINDOW`, `USE_FULL_SCREEN_INTENT`, and `showWhenLocked = true` so the native APK flashes directly over any app or locked screen:

// AndroidManifest.xml Permissions:
<uses-permission android:name="android.permission.SYSTEM_ALERT_WINDOW"/>
<uses-permission android:name="android.permission.USE_FULL_SCREEN_INTENT"/>
<uses-permission android:name="android.permission.WAKE_LOCK"/>
<uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM"/>

// MainActivity.kt Lock-Screen & Over-App Wake:
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O_MR1) {
    setShowWhenLocked(true)
    setTurnScreenOn(true)
}
window.addFlags(
    WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON or
    WindowManager.LayoutParams.FLAG_ALLOW_LOCK_WHILE_SCREEN_ON
)
